# Fuentes incluidas

Las cartas formales usan archivos web locales instalados mediante Fontsource y
archivos TTF locales para incrustación en PDF:

- Source Sans 3 — Adobe Fonts (`adobe-fonts/source-sans`, rama `release`).
- Playfair Display — The Playfair Display Project Authors
  (`fonts/Playfair-Display`).
- Cormorant Garamond — The Cormorant Project Authors
  (`CatharsisFonts/Cormorant`).

Las tres familias se distribuyen bajo la SIL Open Font License 1.1. El texto completo se encuentra en `OFL-1.1.txt` y también dentro del archivo `LICENSE` de cada paquete `@fontsource` instalado.
